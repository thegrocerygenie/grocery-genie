Principles

How we sequence.

Capture before opinion. No release proposes recommendations on top of data the user hasn't yet generated. Every "smart" feature lives behind a thin honest one.

One bet per release. 1.1 is prices. 1.5 is sharing. 2.0 is pantry. 2.5 is intelligence. 3.0 is taste. We ship the bet, then expand it before moving on.

The graceful empty state is the spec. Every screen works on day one with zero data, and every screen gets better as data accumulates. If a feature requires a year of history to be useful, it doesn't ship until that history exists.
