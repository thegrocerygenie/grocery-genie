## Learned this session

- Container restarts: about eight in one day, often mid-run. Reports were recovered with `scripts/agent-report.py` every time. Rerun `setup-env.sh` with all live ids after each one.
- The auto-mode classifier refused agents' `git push` of task branches (DA-2, DA-3, DA-9). After the user's explicit approval ("Yes, all task branches"), the coordinator pushed the agent's local commit itself (`git push origin <sha>:refs/heads/<branch>`). Ask first; don't assume.
- A per-request disconnect check behind `BaseHTTPMiddleware` never fires. The reviewer reproduced it, and no test had covered the wiring. Ask reviewers to break the wiring, not just the unit.
- Implementers sometimes skip the full Postgres rerun after a "test-only" fix, or write component tests after the code. Name both in the review prompt, and have the reviewer break the code to confirm the tests fail.
- Agents write scripts into the shared scratchpad and can overwrite each other's (`da8-journey.sh`). Tell agents to prefix scratch files with their task id.
- Concurrency findings came from this phase's new flows (two screens answering one suggestion). DA-5 established a lock order: items in id order via `_lock_items`, then suggestions. Every later task that locks items must follow it, with a pinned order test.
- The user prefers "fix nits, then merge" on every task; offer it as the recommended option.
