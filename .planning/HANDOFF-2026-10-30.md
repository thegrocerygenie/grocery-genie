## Gotchas

What the repo and memory already record (`expo install --check` needs `EXPO_OFFLINE=1` here, CocoaPods needs a UTF-8 locale, no `expo-dev-client`, the Expo CLI patch) is in memory `native-build-gotchas` and `docs/launch-open-items.md`. Not recorded elsewhere:
- **Port 8081 clash:** a voiceai process sometimes holds `127.0.0.1:8081`. Then `exp://127.0.0.1:8081` and `exp://localhost:8081` load the wrong server. Check with `lsof -nP -iTCP:8081 -sTCP:LISTEN`, and open Expo Go at the Mac's LAN address (`ipconfig getifaddr en0`).
- **Simulator input:** iOS 27 taps are often dropped and screenshots can be stale. Prefer deep links (`grocerygenie://…` in a native build, `exp://<host>:8081/--/…` in Expo Go), use `touch_path` with a 120 ms hold for taps, and take a second screenshot before deciding a tap failed.
- **Metro with `CI=1`:** it doesn't watch files. Restart it after every JS change, or the app runs old code.
- **TanStack Query:** every observer of one query key must pass the real `queryFn` (share a `queryOptions` object). An observer's options become the query's options, and invalidations and retries run with them (#55).
- **Test data:** the local dev DB holds throwaway users (`a11y-…`, `native-…@example.test`) and an "A11y Mart" receipt on the RC03 tester. Harmless; delete them if they get in the way.
