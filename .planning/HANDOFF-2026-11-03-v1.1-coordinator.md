## Gotchas learned

- A backgrounded `npm ci` once failed silently (EUSAGE): read the log, don't trust the exit notice.
- `tests/api/test_account_deletion.py` fails until account deletion covers every new table holding user rows: add the delete and a row in the test's setup.
- `docker/.env.production.example` must copy the `docs/DEPLOYMENT.md` env block (`tests/core/test_deployment_env_doc.py`).
- `scripts/check-traceability.py` cannot read a jest title containing `"`.
- Async SQLAlchemy: load relationships explicitly (`await db.refresh(obj, ["rel"])`) before touching them; a lazy load raises `MissingGreenlet`.
- Prettier warns on 4 files already on `main`; not part of `validate-mobile`.
